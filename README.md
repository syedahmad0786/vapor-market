# Vapor Market

Type any object, concept, or nonsense phrase. Get a full polished fake product landing page: hero, fake logo row, features, testimonials, pricing, and a Buy Now button that will not sell you anything.

Live: after deploy. Repo: https://github.com/syedahmad0786/vapor-market

Shareable URLs are deterministic. Same seed, same page:

```
/?p=sentient-toaster
```

No backend. No AI. Copy is combinatorial from `src/copy.ts`. Layout, accent, and dark/light theme come from hashing the product slug in `src/seed.ts` (six templates).

## Run

```bash
npm install
npm run dev
```
